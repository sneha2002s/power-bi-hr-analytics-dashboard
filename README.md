HR Analytics Dashboard – Power BI

Project Overview

This project explores Human Resources (HR) data through an interactive dashboard built using Microsoft Power BI. The dashboard helps visualize workforce metrics and identify patterns that can support HR decision-making.

Objectives

Analyze employee data and workforce distribution.

Visualize employee attrition patterns.

Explore workforce demographics across age groups and gender.

Understand employee distribution across job roles and education fields.

Present HR metrics through an interactive dashboard.
